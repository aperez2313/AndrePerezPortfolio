# Projects

One folder per project, named in lowercase with dashes (for example `flyer-qa-tool`). Copy the `_TEMPLATE` folder to start one. Start with 3 to 5.

Each folder gets:
- `notes.md` (copied from the template)
- 2 or 3 screenshots, BLURRED BEFORE YOU COMMIT: names, prices, UPCs, partner fees, customer info.
